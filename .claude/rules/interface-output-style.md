# Output presentation

The selected Output Style is `adhd`, realized as the `ADHD Explanatory` output style supplied by the `adhd-output-style@claude-settings` plugin. Only that style is active; any other installed output style, including one supplied by another plugin, stays installed but inactive. No Rule, Skill, or other source declares response style or format; they may require only what must be reported.

Every Output Style may change organization, tone, detail, and format, but always preserves exactly: coding instructions, technical meaning, identifiers, commands, paths, code, evidence, warnings, uncertainty, and required decisions. Shorten expression only when no required substance is lost.
